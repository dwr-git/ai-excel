# AI-Excel — установка на сервер

Табличный редактор в браузере, устроенный как Microsoft Excel: лента, формулы и функции, форматы чисел,
таблицы, диаграммы, сортировка и фильтры, сводные таблицы, условное форматирование; книги .xlsx
(а также .xls, .xlsb, .ods, .csv). Со встроенным помощником на вашей локальной модели и книгами на вашем сервере.
На сервере нужны только **nginx + PHP + Ollama** (или совместимый шлюз) — то, что у вас уже есть. Ничего компилировать не нужно.
Редактор полностью автономный: всё загружается из его папки, интернет и сторонние сайты не нужны.

## Установка (5 минут)

1. **Скачайте готовую сборку.** GitHub → репозиторий `ai-excel` → справа **Releases** →
   верхняя «Сборка N — дата» (с пометкой Latest) → файл `ai-excel-build-N-ГГГГ-ММ-ДД.zip`.
   Какая сборка стоит у вас, видно в шапке панели помощника: «Модель: … · сборка N».
2. **Распакуйте** — внутри одна папка `ai-excel`.
3. **Положите её на сервер** рядом с остальными приложениями: `/app/src/ai-excel/`.
   Папку можно назвать как угодно — все пути внутри относительные. Помощник и хранилище сами найдут
   ваш `auth.php` на два уровня выше и через него — `config.php`, `.env`, адрес Ollama и модель.
4. **Папка для книг создаётся сама**: `storage/ai-excel` рядом с корнем сайта.
   Проверка: `https://ваш-домен/ai-excel/api/files.php` → `{"ok":true,…}`.
5. **nginx** — готовые блоки в `nginx.conf.example` (большие запросы и долгое ожидание модели).
6. **Откройте** `https://ваш-домен/ai-excel/`.

Обновление — то же самое: скачать новый zip и заменить папку (свой `studio/config.js` сохраните).
Каждая сборка лежит в своей папке `b/<номер>/`, а `index.php` открывает самую новую залитую целиком,
поэтому обновление не смешает файлы разных сборок. Если заливаете по FTP, лучше включить «Перезаписывать всегда».

## Книги

- **Ctrl+S** сохраняет книгу в «Мои книги» на сервере (значок папки в панели помощника).
  Первый раз спросит имя, дальше сохраняет туда же. «Сохранить как…» — копия под новым именем.
  Сохраняется всегда в .xlsx: книга, открытая из .xls, .ods или .csv, сохраняется новой книгой .xlsx рядом с исходной.
- **Мои книги**: список с датой и размером, поиск, открыть, переименовать, удалить (в корзину `.trash`),
  «С компьютера…» — открыть .xlsx/.xls/.ods/.csv с компьютера.
- У каждого пользователя своя папка. Книга с сервера сохраняется туда сама раз в минуту, если в ней есть изменения.
  Если сохранить не удалось (нет связи), копия остаётся в браузере, и панель предложит её открыть.
- «Файл › Экспорт» и «Поделиться» — PDF, CSV и веб-страница скачиваются в браузере.
- Новые книги — «Книга1», «Книга2»…, лист A4.

## Помощник

- **Совет** — объясняет, где найти функцию и как написать формулу, смотрит данные, находит ошибки. Ничего не меняет.
- **Сделай** — сам правит книгу: заполняет ячейки, пишет формулы, сортирует и фильтрует, оформляет таблицы,
  форматы чисел, границы, строит диаграммы. Каждое действие отменяется (Ctrl+Z).
- **Быстрые задачи** (значок с квадратиками): оформить как таблицу, границы, ширина столбцов, денежный и процентный
  формат, сортировка, фильтр, удаление дубликатов, диаграмма, A4 и альбомная ориентация — в одно нажатие;
  и готовые просьбы помощнику (выводы по данным, ошибки в данных, строка итогов, сводка по категориям…).
- **Быстрая строка — Ctrl+Shift+Пробел.**
- Формулы редактор понимает с английскими именами функций и запятой между аргументами: `=SUM(B2:B9)`,
  `=IF(C2>0,"да","нет")`. Помощник пишет их так сам.

### ИИ у выделения

Выделите ячейки — у правого нижнего угла выделения появится кнопка **ИИ**. То же меню есть в контекстном
меню ячеек (правая кнопка → **ИИ-помощник…**) и открывается у выделения по **Ctrl+Alt+Пробел**. В меню:

- **Формулы**: объяснить формулу, написать формулу по описанию («сумма по столбцу C, где в B — Минск»), исправить формулу;
- **Очистка**: убрать лишние пробелы и привести даты, числа, телефоны к одному виду; исправить опечатки;
  имена с заглавной буквы; вытащить числа из текста;
- **Перевод** ячеек на русский, английский, белорусский и другие языки;
- **Анализ**: кратко о данных, выводы и тренды, поиск ошибок и выбросов, разложить строки по категориям;
- **Диаграмма**: подобрать тип диаграммы для выделенных данных.

В строке сверху можно написать свою просьбу и нажать Enter. Модель видит выделенные ячейки (значения и формулы)
и начало листа. Ответ сначала показывается в окошке: **Заменить выделенное** (новые значения тех же размеров; ячейки
с формулами не трогаются), **Вставить справа**, **Вставить в ячейку** (формулу), **Вставить диаграмму**,
**Вставить под выделением** (текст), **Копировать** или **Ещё вариант**. Отмена — Ctrl+Z.
Задания для модели — в `api/context.php`.

## Настройки в `.env` (необязательно)

| Переменная | Что делает | По умолчанию |
|---|---|---|
| `AI_EXCEL_DATA_DIR` | Где хранить книги | `storage/ai-excel` рядом с корнем сайта |
| `AI_EXCEL_MODEL` | Модель помощника (нужны tools; для «глаза» — картинки) | `GLOBAL_MODEL` |
| `AI_EXCEL_OLLAMA_URL` | Адрес Ollama или шлюза | `OLLAMA_IP:OLLAMA_PORT` |
| `AI_EXCEL_CONTEXT` | Размер контекста | `GLOBAL_MODEL_CONTEXT` или 32768 |
| `AI_EXCEL_TIMEOUT` | Сколько секунд ждать модель | 180 |
| `AI_EXCEL_MAX_TOKENS` | Длина ответа | 2048 |
| `AI_EXCEL_AUTH_FILE` | Путь к `auth.php`, если папка лежит не в `/app/src/` | ищется автоматически |
| `AI_EXCEL_TALERS_FILE` | `talers.php` кабинета для ИИ у выделения (цена операции и остаток) | `cabinet/talers.php` рядом с корнем сайта, если он есть |
| `AI_EXCEL_ALLOW_ANON` | `1` — без входа (только для проверки!) | выключено |

В `studio/config.js` (правится прямо на сервере): `homeUrl` — куда ведёт домик в правом верхнем углу,
`autosaveSeconds`, `openOnStart`, `filesOnStart`, `aiMaxCells` — сколько ячеек выделения отправлять модели.

## Если что-то не работает

| Признак | Что проверить |
|---|---|
| Редактор не запускается | Под полосой загрузки написано, какой файл не пришёл и почему |
| После заливки по FTP — старая версия | Программа заливки пропустила файлы того же размера: включите «Перезаписывать всегда» |
| В панели «Нужно войти в систему» | Вход в вашу систему в этом же браузере и на этом же домене |
| «Не удалось создать папку для файлов» | Создайте `storage/ai-excel` и дайте PHP право записи, или задайте `AI_EXCEL_DATA_DIR` |
| Ошибка 413 / 504 | `client_max_body_size` / `fastcgi_read_timeout` — см. `nginx.conf.example` |

## Для разработчика

- Сборку делает GitHub Actions (`.github/workflows/studio.yml`) на каждое изменение ветки `main`.
- Мост редактора: `apps/gridcraft-web/src/web/bridge.rs` — `window.aiexcel.request(метод, параметры)`,
  те же методы, что у канала управления (`crates/ui-egui/src/control.rs`). В консоли браузера:
  `await aiexcel.execute('cell.set', {cell: 'A1', input: '=1+2'})`.
- Сохранение на сервер: `Services::save_to_page` → событие `aiexcel:save` → `api/files.php`.
- ИИ у выделения: `Services::ai_assist` (кнопка у выделения в `grid.rs` и пункт контекстного меню) → событие `aiexcel:ai`.
