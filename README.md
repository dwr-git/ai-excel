# AI-Excel

Табличный редактор в браузере, устроенный как Microsoft Excel, с помощником на вашей локальной модели и
книгами на вашем сервере. Ставится папкой на сервер с nginx и PHP: инструкция — [`studio/README.ru.md`](studio/README.ru.md),
что нового — [`studio/CHANGES.ru.md`](studio/CHANGES.ru.md). Готовые сборки — в Releases.

Основано на [GridCraft](https://github.com/storytold/sheetcraft) (MIT OR Apache-2.0); описание исходного проекта —
[`docs/README-upstream.md`](docs/README-upstream.md), лицензии — [`NOTICE`](NOTICE).
